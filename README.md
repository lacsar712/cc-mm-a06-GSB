# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 巷道热力（文字表，无图）

顶栏「巷道热力」按巷道名前缀统计每个前缀下的报警条数与正常条数，并列出命中行编号。

- 前缀长度由检查员（gasman）设定，保存在服务端，只影响现场表。
- 检查员可签发热力快照，快照冻结当时的前缀长度、各前缀计数和命中行编号集合；之后改前缀长度，旧快照不动。
- 旁观账号（viewer）能看现场表和快照，但不能改前缀、不能签发。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 顶栏进「巷道热力」，前缀长度设为 2，看到「回风」报警 1、「东翼」正常 1；点「签发热力快照」。
5. 把前缀长度改成 3，现场表变为「回风巷」等三字前缀；打开刚签发的旧快照，仍按长度 2 计数（「回风」报警 1）。
6. viewer 打开「巷道热力」：现场表和快照可看，前缀长度输入框、保存与签发按钮均不可用。
