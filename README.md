# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 巷道热力

顶栏「巷道热力」按巷道名前缀把测点分组，文字列出每个前缀下的报警条数与正常条数（不出图）。检查员可调整前缀长度（1–8，默认 2），服务端实时重算现场表；检查员还能签发热力快照，冻结当时的前缀长度、各前缀计数与命中行编号集合。之后再改前缀长度只影响现场表，旧快照仍按签发时的长度计数。viewer 能看现场表和快照，不能改前缀、不能签发。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 打开顶栏「巷道热力」，前缀长度设为 2，签发热力快照；再把前缀长度改成 3，现场表按 3 重算，打开旧快照仍按长度 2 计数。
5. viewer 打开「巷道热力」能看现场表和快照，但没有「保存前缀长度」「签发热力快照」按钮，直接调接口也会返回 403。
